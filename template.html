Paste a list of files

One per line. Doc numbers or file names both work, with or without revision and extension, e.g. 2000-F12-DRG-ME-10456 or 2000-F12-DRG-ME-10456_0_APP.pdf. The latest revision of each is picked. Numbered revisions rank above lettered ones, so Rev 0 beats Rev C.

How it works

  1. Open this file in the browser you use for SharePoint, and make sure you are signed in to SharePoint in another tab.
  2. Search and use the pills to narrow the list. Pills in the same group widen the match, pills in different groups narrow it.
  3. Tick the items you want. Ticks are remembered in this browser.
  4. Click Test one file first. If the browser asks to allow pop ups or multiple downloads from this page, choose Allow.
  5. Or click Paste a list, paste doc numbers or file names one per line, then Tick and download. The latest revision of each is used.
  6. Click Download all ticked. Each file is opened one after the other with a short gap. Leave the page open until the bar is full.

If nothing arrives with the Background method, switch to New tab per file. Force download asks SharePoint to save the file rather than preview it. If files open in a preview instead of saving, untick it to see whether the links work at all.

Update register loads a newer copy of the register (.xlsm, .xlsx or .csv with URL, Doc Number, Rev, Status and Title columns). It is kept in this browser until you choose Use built in register.
